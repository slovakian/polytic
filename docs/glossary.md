# Glossary

Canonical terms for Polytic. Use these words, with these meanings, in docs, code, and UI
copy.

**Polytic**: The brand, and the short product name.

**Polytic Party**: The full product name and domain (polytic.party). Also the name of
the distributable skill.

**Grill**: The interview itself: the AI asks, probes, and challenges the coherence of
the user's views. Also used as a verb ("grill me").

**Session**: One grill, from the first question to the verdict (or until the user stops).

**Skill**: The distributable prompt that runs the grill inside the user's own AI agent.

**Finding**: One thing the AI has learned about the user's politics during a session.

**Evidence**: What the user actually said that supports a finding: a quote or close
paraphrase. A finding without evidence is an assertion.

**Tension**: Two findings that appear to conflict. The grill names tensions and asks the
user to reconcile them; it never resolves them toward a side.

**Case file**: Everything the AI has recorded about the user in a session: findings,
tensions, open topics, and coverage.

**Verdict**: The considered result at the end of a session: primary labels from the
label library, a narrative, a read on each dimension, and caveats. A **partial verdict**
is delivered when the user ends early.

**Dimension**: One axis of political space from the dimension taxonomy.

**Label**: An established political term from the label library that a verdict anchors
to.

**Profile**: A user's saved political picture, built from their sessions over time.
Requires login; not in v1.
