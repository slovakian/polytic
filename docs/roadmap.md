# Roadmap

> **v1 is Phase 0 only.** Build the grilling skill and the showcase/distribution site.
> Do not let later phases leak into v1 decisions. This roadmap is a living document and
> will be reordered as the project develops — treat it as direction, not a contract.

Each phase is roughly a prerequisite for the next.

## Phase 0 — Skill + site (build now)

- The distributable **grilling skill** (skills CLI + copy-paste from the site).
- A **showcase/distribution site** (this repo): explains the thesis, hands out the
  skill, install instructions. No first-party LLM calls yet.
- The versioned **dimension taxonomy** and **label library** assets.

## Phase 1 — First-party grilling + profiles

- In-app grilling chat (LLM calls run by us), so we control the long session.
- Saved **profiles** with the verdict and its reasoning.
- The persistent **answer + interpretation store**: each user accumulates their raw
  answers and the AI's interpretations, retrievable to refine their profile over time.

## Phase 2 — Alignment

- Tag thinkers, politicians, and online personalities using the same label library.
- Show how closely a user's profile aligns with them on shared vocabulary.
- This is the highest-value, most viral demonstration of why Polytik beats the compass
  — intentionally ahead of the heavier social/community work.

## Phase 3 — Social layer

- Public profiles, shareable grilling sessions, public prompts people respond to.

## Phase 4 — Discourse

- AI-arbitrated asynchronous discussions coordinated by a neutral arbiter; eventually
  live debates.
