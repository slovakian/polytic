# Design philosophy: lively colour, serious substance

Polytic Party is built on shadcn/ui but should feel **lively and friendly**, using many
different colours across the site's elements rather than one restrained accent. A rainbow,
multi-hue palette is the identity. Specific colours and components are not decided here.

**Playful look, serious voice.** The warmth comes from the design, never from the AI.
The grilling voice stays sharp, brief, and neutral: no praise, no validation, no
flattery, because those break "map, don't grade" (`docs/principles.md`). The friendly
interface is what makes rigorous questioning feel approachable.

**Colour is decorative for now.** Hues are applied for liveliness without encoding
meaning.

## Shelved, not rejected

**Colour identifies the topic, never the side.** Each dimension could own a hue across
the whole site (chat, results, a future live profile), while positions _within_ a
dimension are never coloured by direction. No red-means-right, ever. Something like this
may return once dimensions exist. Whatever form it takes, colour must never encode
political direction: party colours differ by country and would make the product read as
partisan.
