# A person is a set of Beliefs on fixed, two-layer Dimensions

Polytic maps a person on a **fixed, shared, comprehensive set of Dimensions** in two
layers, Foundation and Political, and records each placement as a **Belief** that
carries a Position, a separate Pull for each Pole, the person's State, the session's
Coverage, Reasons, and Evidence. Labels are configurations of positions _and_ reasoning;
Reference Figures are encoded with the same model. The full model is in
`docs/framework.md`.

We rejected the alternatives the literature offers when used alone:

- **Concepts first** (Freeden's morphology as the backbone): the most faithful to how
  traditions differ, but comparing two concept graphs is unreliable, hard to show, and
  impractical to hand-encode across a Reference Figure catalog. Morphology lives on as
  Reasons and Label definitions instead.
- **Values first** (Moral Foundations, Schwartz): explains intuitions, not what the
  state should do, and pushes toward psychological diagnosis. It is a probing toolkit
  only, never scored.
- **A single Position per Dimension**, as in most political tests: it makes "torn" and
  "indifferent" identical and averages real conflict into a fake centre. Pull is
  recorded per Pole for that reason.

Consequences: every Dimension must be authored with academic lineage and kept stable,
because changing the set changes what every stored Belief and Reference Figure means.
Views no Dimension fits are recorded as Off-map Beliefs rather than forcing the set to
grow on the fly.
