# Naming: Polytic and Polytic Party

**Polytic** is the brand and the short product name. **Polytic Party** is the full
product name and the domain (polytic.party), and also the name of the distributable skill
(`polytic-party`). Use "Polytic Party" where the full name reads naturally
(page titles, the skill, first mention) and "Polytic" anywhere else. "Polytic" stays the
codebase and package namespace (`@polytic/*`).
