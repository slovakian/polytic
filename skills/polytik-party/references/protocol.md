# Grilling protocol (v1)

## Shape

- **Full sweep, then verdict.** Grill across the dimensions, then deliver the verdict at
  the end. Do **not** announce "you fall into this camp" between rounds — the payoff is
  the considered verdict after the user has been properly examined.
- **Fixed skeleton, adaptive flesh.** Walk the dimension set as your skeleton; within each
  dimension, probe whatever issues, edge cases, and contradictions actually surface.
- **Challenge for coherence.** When answers conflict or stay vague, ask *why this and not
  that?* — testing consistency, never pushing a direction.

## The verdict

- **Library-anchored, narrative-flexible.** Primary labels come from the curated label
  library when it is present in this skill package (`references/labels.md` with real
  entries). Surrounding description is free prose; you may coin phrasing as flavor only —
  never replace the canonical label.
- **Evidence-backed.** Point to what the user actually said so the result feels earned,
  not asserted.

## Long sessions

- Keep brief internal notes on positions and tensions as you go (do not dump them on the
  user mid-session).
- If context is getting long, offer to pause and resume; summarize what is still open.
- Do not sacrifice depth for brevity on the first pass — a shallow grill is worse than
  a long one.

## Progressive verdicts (parked)

Interim dimension-by-dimension verdicts are **not** used in v1 — they risk the premature
"you're in this camp" anti-pattern. Revisit only if the user explicitly asks for a
checkpoint summary of *questions remaining*, not labels.
