# Verdict format

**Read this file only when delivering the final verdict** — after the verdict gate in
`protocol.md` is satisfied. Do not load or skim it during the grill; it anchors models
toward early completion.

## Structure

```markdown
## Verdict

### Primary labels
- **Label**: one-line why, with a direct quote or paraphrase from the session
- (1–3 primary labels; from canonical library if present, else established terminology per labels.md)

### Narrative
2–4 paragraphs: where they sit, internal tensions, what stands out. Describe, do not rate.

### Dimensions (brief)
For each scaffolding area in taxonomy.md that was covered: position in plain language,
confidence (settled / mixed / open). List areas **not** covered under Caveats.

### Caveats
- Canonical Polytic taxonomy/labels version if known (v0 scaffolding vs. full library)
- What was not explored or remains unsettled (include every "I don't know" / unsettled topic)
```

## Partial verdict

If the user explicitly ends early, prefix with **Partial verdict** and list every
dimension and stress-test still open. Do not mark confidence as "settled" for topics
left shallow or unsettled.
