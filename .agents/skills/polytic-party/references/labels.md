# Label library

## The model

- **Anchored.** Verdict **primary** labels must come from the curated library when this
  file lists canonical entries.
- **Flexible.** Surrounding narrative is free prose; coined phrasing is flavor only.
- **Why anchored matters.** Comparison across people and thinkers requires shared
  vocabulary.

## Canonical status

When this file contains a structured catalog (term, definition, implied dimensions,
neighbors), pick **primary** labels only from that catalog.

When the catalog is not yet present (v0), use **established political-science and public
discourse terminology** (e.g. liberalism, conservatism, libertarianism, social democracy,
communitarianism, anarchism, nationalism, etc.) — terms readers would recognize in a
serious poli-sci context. Do **not** invent branded neologisms as primary labels. You may
add a short coined *subtitle* as flavor if it genuinely fits.

Always note in the verdict if the canonical Polytic label library was not bundled with
this skill install.
